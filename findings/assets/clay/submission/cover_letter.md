What this package claims:

- There is a concrete, scriptable theorem-to-artifact map for these four
  requirements.
- The mapped Lean modules build in the current repository state.

What this package does not claim:

- It does not assert prize adjudication outcome.
- It does not replace independent review; it is a reproducibility and navigation
  bundle for that review.
